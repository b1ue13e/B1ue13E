## 研究方向

- **决策学习与优化：**偏好学习、AHP 和 FlowSort、策略性多准则决策，以及混合整数问题的学习引导搜索。
- **推理与智能体：**额外计算的价值、序贯语义反馈，以及通过实验改进的智能体。
- **可靠机器学习：**表征动力学与 grokking、结构先验失配，以及变化环境中的时序学习。
